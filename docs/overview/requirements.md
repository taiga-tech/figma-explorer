# 要件定義

## 1. 概要

Figma Draftsに蓄積されたファイル一覧を整理し、用途、案件、機能、状態ごとに見つけやすくするChrome拡張機能を作成する。

対象はFigmaファイルの中身ではなく、Figmaのファイルブラウザ上に表示されるDraftsのファイル一覧とする。

初期版では、Figma上に実フォルダを作成せず、Chrome拡張機能側の保存領域に仮想フォルダと分類情報を保持する。

## 2. 背景

Figma Draftsは個人作業や検証用ファイルを置きやすい一方、ファイルが増えると次の問題が起きる。

- どのファイルが新しいか分かりにくい
- 案件ごとのファイルを探しづらい
- 作業中、確認待ち、完了済みの区別がつきにくい
- 似た名前のファイルが増える
- 不要なファイルや古いファイルが残る
- チームプロジェクトへ移す前のファイルがDraftsに残り続ける

Figmaのプロジェクトはファイルの整理単位だが、公式ヘルプ上ではプロジェクトにサブフォルダはないと説明されている。
そのため、この拡張機能ではFigma本体の構造を変えず、拡張機能側で仮想的な階層を持つ。

## 3. 目的

Drafts上のファイルを視覚的、操作的に整理し、必要なファイルを探しやすくする。

初期版では次を実現する。

- Drafts画面だけで動作する
- 表示中のDraftsファイルを読み取る
- 整理用パネルを表示する
- 仮想フォルダを作成する
- ファイルを仮想フォルダへ分類する
- 未分類ファイルを一覧表示する
- ファイル名で検索する
- 分類情報をローカル保存する
- 整理結果をJSONで出力する

## 4. 初期版で扱わないこと

- Figmaファイル本文の解析
- レイヤー、ページ、コンポーネントの解析
- Figma上での実フォルダ作成
- Draftsからプロジェクトへの自動移動
- ファイル削除
- 権限変更
- チーム共有
- AI分類
- 命名規則チェック
- ラベル管理
- ドラッグ＆ドロップ
- 右クリックメニュー

## 5. 実装方式

Plasmoを使ったChrome拡張機能として実装する。
Figma Drafts画面にContent Scripts UIでReact UIを注入する。

```text
Framework: Plasmo
Language: TypeScript
UI: React
Package Manager: pnpm
Storage: @plasmohq/storage area: "local"
Target: Chrome Extension MV3
Target Page: https://www.figma.com/*
```

## 6. 非機能要件

- **DOM変更耐性**: Figmaの画面構造変更を前提とする。セレクタは多段
  フォールバックで構成し、失敗は計数・可視化する。対応手順は
  `docs/architecture/scan-pipeline.md` に定める
- **データ非損失**: 拡張機能の更新・スキーマ変更でユーザーの分類データを
  失わない。移行規則は `docs/architecture/data-model.md` に定める
- **部分失敗の許容**: 1件の読み取り失敗で全体を止めない。0件はエラーでは
  なく空状態として扱う
- **キーボード操作とアクセシビリティ**: ファイル一覧の基本操作は
  キーボードだけで完結できる。パネルは構造ロール（WAI-ARIA）を持つ
- **テスト可能性**: DOM依存ロジックと純関数を分離し、unit テストと
  DOMフィクスチャテストの対象にする（`docs/architecture/testing-strategy.md`）
- **Figma本体への不干渉**: パネル外のキー入力・クリックに干渉しない

## 7. 実ファイル操作との関係

Figma上で正式にファイルを移動する場合、Draftsからプロジェクトへ移動する。
ただし、Figma公式ヘルプでは、プロジェクトごとに権限があり、ファイル移動によりアクセスできるユーザーが変わる場合があると説明されている。

この拡張機能では、初期版でFigma上の実ファイル移動は行わない。
ユーザーに対しても、分類は拡張機能内の仮想分類であり、Figma本体のファイル移動、削除、権限変更ではないことを明示する。

## 8. 初期版の完成条件

- Chrome拡張機能として読み込める
- Figma Drafts画面でのみ動作する
- Drafts上のファイルカードを読み取れる
- 整理パネルにファイル一覧を表示できる
- 仮想フォルダを作成できる
- ファイルを仮想フォルダへ分類できる
- 未分類ファイルを表示できる
- ファイル名で検索できる
- 分類情報を保存できる
- 再読み込み後に分類状態を復元できる
- スキーマ移行が定義され、旧データを失わずに読み込める
- JSONで整理結果を出力できる
- unit テストと DOM フィクスチャテストが `pnpm test` で通る
- ファイル一覧をキーボードだけで選択・オープンできる
- 実ファイル操作をしないことが画面上で説明されている
