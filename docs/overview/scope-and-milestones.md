# スコープとマイルストーン

## v0.1: Drafts整理の最小版

v0.1では、拡張機能として成立するための最小機能だけを実装する。

### 対象

```text
M1: 起動とDrafts検出
M2: ファイル一覧取得
M3: 仮想フォルダ分類
M4: 保存・復元
M5: 検索
M6: JSON出力
```

### 含める機能

| 機能                        | v0.1 |
| --------------------------- | ---: |
| Plasmoプロジェクト作成      | 対象 |
| Figma Drafts画面判定        | 対象 |
| Content Scripts UI表示      | 対象 |
| Draftsファイルカード検出    | 対象 |
| ファイル名、URL、FileId取得 | 対象 |
| 整理パネル                  | 対象 |
| 仮想フォルダ作成            | 対象 |
| フォルダ階層                | 対象 |
| ファイル分類                | 対象 |
| 未分類表示                  | 対象 |
| ファイル名検索              | 対象 |
| Plasmo Storage保存          | 対象 |
| JSON出力                    | 対象 |
| 初回案内                    | 対象 |

### 含めない機能

| 機能                | 扱い             |
| ------------------- | ---------------- |
| ラベル              | v0.2             |
| 命名規則チェック    | v0.2             |
| 複数選択            | v0.2             |
| 右クリックメニュー  | v0.3             |
| ドラッグ＆ドロップ  | v0.3             |
| アーカイブ候補      | v0.3             |
| 重複候補            | v0.3             |
| JSON復元            | v0.3             |
| チーム共有          | 後続検討         |
| Figma実ファイル移動 | 初期版では対象外 |

## v0.1完了条件

```text
Figma Drafts画面を開く
↓
整理パネルが表示される
↓
表示中のDraftsファイル一覧が取得される
↓
仮想フォルダを作成できる
↓
ファイルをフォルダに分類できる
↓
未分類ファイルを確認できる
↓
検索できる
↓
再読み込み後も分類が残る
↓
JSONで整理結果を出力できる
```
